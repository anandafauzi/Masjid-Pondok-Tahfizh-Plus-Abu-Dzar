Komponen Konsisten

  • Kartu: radius 18px, border 1px emerald 12%, shadow halus.
  • Ikon: outline 1.8px, satu set (stroke) di seluruh layar.
  • Aksen: garis gold tipis + geometric radial pattern.
  • Navigasi: 5 tab, active = emerald + ikon gold.
  • Status merah: hanya countdown ≤30m / ≤5m.
  • Animasi: fade+slide 180ms, angka countdown halus.

Prinsip Data & Waktu

  • Sumber: /api/public/tv-data, tanpa database baru.
  • Offset: serverTime vs perangkat → countdown presisi.
  • WIB: Asia/Jakarta; target UTC absolute.
  • Hijriah: ICU Umm al-Qura + koreksi ±1 hari.
  • Offline: cache data terakhir, badge "Offline".
  • Refresh: harian otomatis + saat data berubah.

Kesiapan Android

  • Foreground service: ongoing notification.
  • RemoteViews: layout compact & expanded terpisah.
  • Alarm: exact alarm +BOOT_COMPLETED +WorkManager.
  • Izin: POST_NOTIFICATIONS (API 33+), sensor, battery.
  • Audio: adzan mengikuti silent/DND.
  • Compose: satu codebase, modular (core/data/ui/feature).
